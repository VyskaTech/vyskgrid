# Security policy

Report suspected vulnerabilities in the VyskGrid platform or the Host app to **security@vyskatech.com**.

- Please include what you found, how to reproduce it, and the version (the app shows it; releases are tagged).
- Do not test against other people's accounts or computers, do not access data that is not yours, and give us a
  reasonable time to fix a problem before you publish it.
- We will acknowledge a report within three working days. We cannot offer rewards at this stage.

The project is a closed beta in test mode and has not had an external security review. Do not rely on it to protect
data you cannot afford to expose; see the [Safety page](https://grid.vyskatech.com/security.html).
